FitIntelligence

Body Performance Analytics and Intelligent Classification System

PythonScikit-learnTensorFlow / KerasDecision TreesNeural Networks
GitHub Repository

Course project for "Introduction to Artificial Intelligence and Machine Learning," submitted to Dr. Mohamed Elhaddad (29 March 2026). Built by a five-person team — Hayam Medhat Wahdan (Team Leader — Decision Tree model, report, and model system), Hoda Mohamed Ezzat (KNN, presentation), Nada Fahmy Fahmy (SVM), Esraa Mohamed Attia (EDA, Linear Regression), and Esraa Shawky Mahmoud (Neural Network).

overview

FitIntelligence documents the complete lifecycle of a machine learning project applied to the public Body Performance Dataset: data understanding, preprocessing, exploratory analysis, model training, validation, and performance evaluation. The dataset describes physical fitness indicators — age, gender, body composition, blood pressure, grip strength, flexibility, and muscular endurance — and the team built models for both a classification task (fitness performance category) and a regression task (explosive leg power).

business problem

Reliably classifying a person's fitness performance level and estimating a physical performance metric from routine biometric measurements requires a rigorous ML workflow — the dataset alone contains data-quality issues (physiologically impossible readings, duplicates, outliers) that need to be resolved before any model can be trusted.

objective

Build and compare five machine learning models — KNN, Linear Regression, Decision Tree, SVM, and a Neural Network — on both a classification task (predicting performance class A–D) and a regression task (predicting broad jump distance, a measure of explosive power), each evaluated across three train/test splits and 5-fold cross-validation, then recommend the best model for each task.

dataset

The Body Performance Dataset (bodyPerformance.csv) contains 13,393 rows and 12 columns before cleaning: age, gender, height, weight, body fat %, diastolic/systolic blood pressure, grip force, sit-and-reach flexibility, sit-up count, broad jump distance, and a performance class label (A = best, D = weakest). broad jump_cm is the regression target; class is the classification target.

data preparation

Domain-specific validity rules flagged physiologically impossible values (e.g. body fat outside 5–60%, blood pressure outside medical ranges, non-positive grip force) as missing, affecting under 1% of rows in every affected column; these were dropped rather than imputed, since imputing physiological measurements risked introducing bias. Duplicate rows were removed. Outliers were assessed with both the IQR method and a 3-standard-deviation rule, with keep/remove decisions made on domain grounds — for example, high sit-up counts were kept as plausible elite-athlete values, while near-zero grip-force readings were removed as instrument error.

exploratory analysis

Most features were approximately normally distributed; age was right-skewed toward younger participants, and flexibility (sit-and-reach) was left-skewed due to participants unable to reach the floor. Grip force, sit-ups, and broad jump were strongly inter-correlated, suggesting a single latent fitness dimension — which motivated engineering a composite total_fitness feature. Body fat percentage was the strongest single negative predictor across every performance metric. The classification boundary between adjacent classes B and C was diffuse across every model tested, the primary source of misclassification.

features / variables

Engineered features included BMI, pulse pressure (systolic − diastolic), grip-to-bodyfat ratio, the composite total_fitness score, age-interaction terms for grip and jump performance, and an ordinal age-group encoding, alongside log-transforms of 12 skewed columns. By mutual-information score, flexibility and sit-up count were the strongest individual predictors of performance class, while the composite total_fitness feature dominated the regression task.

models used

All five required models were implemented for both tasks: K-Nearest Neighbors (with PCA and GridSearchCV tuning), Linear Regression (regression only, OLS), Decision Tree (max-depth tuned via train/test curves), Support Vector Machine (RBF and linear kernels), and a Neural Network (2 hidden layers, BatchNormalization and Dropout, Keras for classification / MLPRegressor for regression). Each was evaluated across 80:20, 70:30, and 50:50 splits plus 5-fold cross-validation.

model evaluation

On the 80:20 split, the Neural Network was the strongest classifier at 76.33% accuracy, ahead of an XGBoost ensemble (72.66%), SVM–RBF (~72.5%), SVM–Linear (~70.0%), Decision Tree (65.46%), and KNN (65.15%). For regression, the Decision Tree Regressor was the strongest model at R² = 0.9684 (RMSE = 6.98 cm), ahead of SVR–RBF (R² ≈ 0.94), KNN Regression (R² = 0.79), the Neural Network regressor (R² ≈ 0.78), and Linear Regression (R² ≈ 0.72).

key findings

Flexibility and core endurance (sit-and-reach and sit-up count) together account for over 53% of the Decision Tree classifier's decision-making power. The composite total_fitness feature carries 94.3% of the Decision Tree regressor's feature importance, almost entirely driving its near-perfect jump-distance predictions. The B↔C classification boundary is the universal challenge across every model, consistent with overlapping biometric profiles between adjacent fitness classes.

business / practical value

The report recommends deploying the Neural Network for a fitness-classification tool and the Decision Tree Regressor for a broad-jump prediction tool, given its interpretability, computational efficiency, and RMSE under 7 cm. Future work identified in the report includes collecting additional features (e.g. VO2 max, training history) to improve the B/C classification boundary and addressing class imbalance with SMOTE.
